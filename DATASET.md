# Dataset Description

## UA-DETRAC Dataset

This project uses the UA-DETRAC (University at Albany Detection and Tracking) dataset for vehicle detection model development and evaluation.

### Dataset Information

- Dataset Name: UA-DETRAC
- Dataset Type: Traffic Surveillance Video Dataset
- Application: Vehicle Detection and Tracking
- Target Classes: Car, Motorcycle, Bus and Truck

### Dataset Access

Dataset information and access:

https://detrac-db.rit.albany.edu/

### Download Instructions

1. Visit the official UA-DETRAC dataset website.
2. Review the available dataset and annotation resources.
3. Download the required traffic video sequences and annotations.
4. Prepare the annotations in the format required by the YOLO training pipeline.
5. Configure the dataset paths before training or evaluation.

### Important Notes

- The complete dataset is not included in this repository.
- Users must download the dataset separately.
- Dataset preparation and annotation conversion may be required before training.

### Demonstration Video

The demonstration video used by the supplied processing script is separate from UA-DETRAC. It should not be treated as a UA-DETRAC dataset sample.
